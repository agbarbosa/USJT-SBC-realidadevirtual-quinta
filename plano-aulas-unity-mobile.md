# Plano de Aulas: Unity 3D com Entrega Mobile

Sequencia de aulas para conduzir a producao de um jogo 3D em Unity com validacao em smartphone Android.

## Aula 1: Escopo, instalacao e projeto minimo

**Data:** 07/05/2026

### Objetivo

Garantir que cada grupo tenha uma ideia pequena, clara e tecnicamente possivel.

### Em aula

- Explicar a importancia do escopo.
- Mostrar exemplos de jogos 3D pequenos.
- Definir grupos e responsavel pelo build Android.
- Apresentar a estrutura minima do GDD.
- Demonstrar criacao de projeto `3D (Built-in Render Pipeline)`.
- Estabelecer o `Built-in Render Pipeline` como padrao da disciplina.

### Atividade da semana

- Instalar Unity Hub e Unity Editor.
- Criar projeto usando o template `3D (Built-in Render Pipeline)`.
- Criar `MainScene`.
- Entregar GDD reduzido.

## Aula 2: Cena 3D, jogador e camera

**Data:** 14/05/2026

### Objetivo

Fazer o aluno sair de uma cena vazia para um prototipo navegavel.

### Em aula

- Criar chao com `Plane` ou `Cube`.
- Criar jogador com `Capsule`.
- Adicionar `Rigidbody` e `Collider`.
- Explicar `Transform`, escala, posicao e rotacao.
- Demonstrar camera fixa ou terceira pessoa simples.

### Atividade da semana

- Implementar movimento.
- Gravar video curto no Editor.
- Criar obstaculos simples no cenario.

## Aula 3: Primeiro build Android

**Data:** 21/05/2026

### Objetivo

Configurar o projeto para Android e realizar a primeira validacao mobile.

### Em aula

- Mostrar Build Settings.
- Explicar Android Build Support.
- Explicar Player Settings.
- Explicar modo desenvolvedor no Android.
- Demonstrar build simples.

### Atividade da semana

- Tentar build Android.
- Entregar APK ou video.
- Registrar o status do build e os ajustes necessarios.

## Aula 4: Objetivos, colisao e pontuacao

**Data:** 28/05/2026

### Objetivo

Transformar a cena em jogo.

### Em aula

- Criar coletavel.
- Usar `OnTriggerEnter`.
- Atualizar pontuacao.
- Criar condicao de vitoria.
- Reiniciar cena ou mostrar mensagem final.

### Atividade da semana

- Implementar objetivo completo.
- Ter inicio, meio e fim jogavel.

## Aula 5: Desafio e regras

**Data:** 04/06/2026

### Objetivo

Adicionar obstaculo, desafio ou dificuldade.

### Em aula

- Obstaculo que causa dano.
- Inimigo com patrulha simples.
- Plataforma movel.
- Timer.
- Area de derrota.

### Atividade da semana

- Escolher um tipo de desafio.
- Gravar video vencendo e perdendo.

## Aula 6: UI, audio e feedback

**Data:** 11/06/2026

### Objetivo

Melhorar clareza para o jogador.

### Em aula

- Texto de pontuacao.
- Tela de vitoria.
- Som de coleta.
- Som de derrota.
- Feedback visual simples.

### Atividade da semana

- Adicionar UI minima.
- Adicionar pelo menos dois sons.
- Atualizar GDD com mudancas.

## Aula 7: Otimizacao mobile

**Data:** 18/06/2026

### Objetivo

Preparar o jogo para rodar melhor em smartphone.

### Em aula

- Reduzir luzes dinamicas.
- Evitar sombras pesadas.
- Usar poucos materiais.
- Evitar texturas grandes.
- Conferir tamanho do build.
- Testar em celular.

### Atividade da semana

- Gerar build atualizado.
- Gravar video no celular.
- Listar tres otimizacoes feitas.

## Aula 8: Apresentacao e entrega

**Data:** 25/06/2026

### Objetivo

Apresentar resultado final e refletir sobre decisoes tecnicas.

### Entrega

- APK final.
- Video de gameplay.
- GDD final.
- Lista de assets externos.
- Divisao de tarefas.

### Perguntas para apresentacao

- Qual era o objetivo do jogo?
- Qual foi a maior dificuldade tecnica?
- O jogo rodou no celular?
- O que foi simplificado durante o desenvolvimento?
- Qual parte do codigo o grupo mais entende?
