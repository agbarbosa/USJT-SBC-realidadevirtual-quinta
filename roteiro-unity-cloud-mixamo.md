# Aula 1: Unity Cloud Studio e Mixamo

**Data:** 07/05/2026

## Objetivo

Conhecer duas ferramentas que apoiam a producao do jogo 3D:

- **Unity Cloud Studio:** ambiente online da Unity para organizacao e servicos ligados ao projeto.
- **Mixamo:** ferramenta da Adobe para escolher personagens 3D e animacoes prontas.

Essas ferramentas ajudam o grupo a pensar o projeto como uma producao completa: ideia, personagem, animacao, organizacao e preparacao para desenvolvimento no Unity.

## Links oficiais

- Unity Cloud Studio: https://cloud.unity.com/studio
- Mixamo: https://www.mixamo.com

## Parte 1: Unity Cloud Studio

### O que observar

Ao acessar o Unity Cloud Studio, observe:

- necessidade de login com conta Unity;
- organizacao de projetos na nuvem;
- relacao entre conta Unity, projetos e servicos;
- possibilidade de centralizar recursos de producao.

### Atividade em aula

1. Acesse: https://cloud.unity.com/studio
2. Faca login com a conta Unity.
3. Observe a tela inicial do Unity Cloud.
4. Identifique onde ficam projetos, organizacao e servicos disponiveis.
5. Registre um print da tela inicial apos o login.

### Discussao rapida

Responder em grupo:

- Qual conta sera usada para organizar o projeto?
- Quem sera o responsavel por manter arquivos e versoes organizados?
- Como o grupo vai compartilhar evidencias do progresso?

## Parte 2: Mixamo

### O que e o Mixamo

O Mixamo permite escolher personagens 3D e aplicar animacoes prontas, como:

- idle/parado;
- caminhada;
- corrida;
- pulo;
- ataque;
- danca;
- queda;
- interacoes simples.

Para o trabalho, o Mixamo sera usado como referencia para personagens e animacoes que podem compor o prototipo.

## Parte 3: Escolher um personagem

1. Acesse: https://www.mixamo.com
2. Faca login.
3. Entre na area de personagens.
4. Escolha um personagem coerente com a ideia do jogo.
5. Registre um print do personagem escolhido.

Criterios para escolher:

- combina com o tema do jogo;
- pode ser usado em uma cena simples;
- nao exige muitos detalhes visuais;
- funciona bem em jogo mobile;
- tem animacoes adequadas ao objetivo do grupo.

## Parte 4: Escolher uma animacao

1. Com o personagem selecionado, procure uma animacao.
2. Teste pelo menos tres opcoes.
3. Escolha uma animacao principal para o prototipo.

Animacoes recomendadas para inicio:

- idle;
- walk;
- run;
- jump;
- attack simples;
- interact;
- victory.

Registrar:

- nome da animacao escolhida;
- motivo da escolha;
- print da pre-visualizacao.

## Parte 5: Download para uso posterior

Quando o professor orientar a importacao para o Unity, o grupo podera baixar o personagem ou a animacao.

Configuracao recomendada para download inicial:

- formato: `FBX`;
- skin: `With Skin`, quando baixar personagem completo;
- skin: `Without Skin`, quando baixar apenas animacao para personagem ja escolhido;
- frames per second: manter o padrao sugerido pela ferramenta;
- keyframe reduction: manter configuracao padrao.

Observacao: nesta primeira aula, o foco e escolher e entender o fluxo. A importacao detalhada para o Unity pode ser feita em aula posterior.

## Entrega da Aula 1

O grupo deve entregar:

- GDD reduzido;
- print do projeto Unity criado;
- print do Unity Cloud Studio apos login;
- print do personagem escolhido no Mixamo;
- print de uma animacao escolhida no Mixamo;
- nome do responsavel pelo build Android.

Modelo de registro:

```text
Grupo:
Nome do jogo:
Responsavel pelo build Android:
Conta/organizacao usada no Unity Cloud:
Personagem escolhido no Mixamo:
Animacao inicial escolhida:
Como esse personagem combina com o jogo:
```

## Cuidados importantes

- Evitar escolher personagem apenas pela aparencia.
- Preferir personagem que combine com a mecanica principal.
- Nao transformar a escolha de personagem no centro do projeto.
- Lembrar que primeiro o jogo precisa funcionar; visual e animacao entram como apoio.
- Registrar os assets externos usados no GDD ou em arquivo de creditos.
